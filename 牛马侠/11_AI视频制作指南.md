## 二、角色一致性设置（关键！）

AI视频最大的挑战是角色跨镜头不一致。解决方法：

### 方法一：主角参考图固定
在即梦/可灵里：
1. 先生成一张"主角参考图"——用以下提示词：
   > `25岁中国男性，微胖，蓝色格子衬衫，黑框眼镜，现代办公室背景，正面镜头，自然光，写实风格`
2. 把这张图保存为"主角基准图"
3. 每次生成新场景，上传这张基准图作为"角色参考"

### 方法二：场景固定词缀
每个场景描述词前，固定加上这段：

```
[角色保持一致] 主角：中国男性25岁微胖，蓝色格子衬衫，黑框眼镜。
Boss：中国男性42岁精瘦，发际线后移，黑色西装，假笑。
场景：[具体场景描述]
动作：[具体动作描述]
镜头：[镜头角度]
```

## 三、谎言红字特效制作方法（剪映）

这是全剧最关键的视觉特效，必须做好。

**步骤**：
1. 在剪映中，找到要添加红字的片段
2. 添加文字图层：
   - 字体：楷体
   - 颜色：#FF2020（鲜红色）
   - 透明度：75%
   - 描边：白色1px
3. 动画设置：
   - 入场动画：淡入，0.3秒
   - 停留：根据台词长度
   - 出场动画：淡出，0.2秒
4. 位置：放在角色头顶，略偏右，不遮住脸
5. 加一个轻微的"抖动"关键帧动画，让字体微微颤动

**音效**：配合"叮"的短促音效（剪映音效库有）

## 七、剪辑节奏要点

### 卡点原则
- 每个爽点前，加0.5秒静默
- 爽点发生时，切慢动作（0.7x速度）
- 爽点后，立刻切到反应镜头（角色表情）
- 每集最后钩子：最后5秒，BGM渐弱，只留环境音，字幕缓缓出现

### 镜头切换节奏
- 正常对话：每3~5秒切换一次
- 紧张对峙：每1~2秒切换一次（快切）
- 独白/OS旁白：静止镜头或极慢推进，5~8秒

## 八、红果平台发布策略

### 标题公式（选其一）
- 「老板当众露馅，员工集体哭了」
- 「打工人变超人，专治职场PUA」
- 「他喝了一杯奶茶，从此老板不敢骗他」
- 「全公司谎言被实时播出，那个沉默的程序员笑了」

### 封面图要求
- 人物表情戏剧化（谎言红字出现的瞬间）
- 加粗大字：本集核心冲突
- 不要纯黑封面，用高饱和截图

### 发布节奏
- 前三集，**一次发完**（让算法有足够数据测试）
- 第4~7集，**每天一集**
- 第8~10集，**隔一天一集**（制造等待感）

### 互动话术（每集评论区置顶）
```
第1集：你们上班被PUA过吗？说出你的故事👇
第3集：如果你是牛小马，你会帮小周吗？
第5集：你身边有张总这样的老板吗？
第8集：看到这集的那一刻你什么感受？
第10集：你希望下一季牛马侠去哪个行业？
```

## 九、制作时间线建议

| 周次 | 任务 |
|------|------|
| 第1周 | 固定角色基准图，制作第1~3集视频素材（AI生成+基础剪辑） |
| 第2周 | 完成第1~3集后期（配音+字幕+特效），制作第4~6集素材 |
| 第3周 | 完成第4~6集，制作第7~10集素材 |
| 第4周 | 完成第7~10集，全集质检，准备封面和标题 |
| 发布日 | 发布第1~3集，开始执行发布节奏 |

---

> **核心原则**：宁可每集慢一天，也要保证第08集的投影仪大场面打磨到位——那是全剧的记忆点，决定能否出圈。
